# 📚 DSA Notebook

> My personal **Data Structures & Algorithms (DSA)** learning journey — notes, implementations, problem-solving practice, and patterns.

This repository contains everything I learn while studying DSA, starting from programming fundamentals and gradually moving toward advanced topics like **Dynamic Programming, Backtracking, Graphs, and Advanced Algorithms**.

The goal of this repository is not just to collect solutions, but to build a strong understanding of **how and why** each algorithm and data structure works.

---

## 🎯 Goals

- Build strong DSA fundamentals from scratch
- Understand the logic behind each algorithm
- Practice problem-solving regularly
- Implement data structures and algorithms
- Analyze **Time & Space Complexity**
- Maintain organized notes for future revision
- Track my progress throughout my DSA journey
